# FamilyHub UI

Frontend application for **FamilyHub**, a simple family expense tracking application.

The UI is built with **React, TypeScript, and Vite** and communicates with the FamilyHub Backend through a REST API.

## Architecture

```text
Browser
   |
   v
React / TypeScript / Vite
   |
   | HTTP / REST API
   v
FamilyHub Backend
```

## Tech Stack

* React
* TypeScript
* Vite
* React Router
* REST API
* Docker

## Features

* User registration
* User login
* JWT authentication
* Dashboard
* Expense list
* Add expense
* Edit expense
* Delete expense
* Categories
* Monthly budget
* Monthly spending summary

## Prerequisites

* Node.js 20+
* npm
* Docker
* FamilyHub Backend running locally
