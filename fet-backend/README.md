# FamilyHub Backend

Backend API for **FamilyHub**, a simple family expense tracking application.

## Tech Stack

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy
* Alembic
* Pydantic

## About

This repository contains the backend API for FamilyHub.

The backend will provide functionality for:

* User authentication
* User management
* Expense management
* Categories
* Monthly budget
* Dashboard data

The application will use PostgreSQL as its database.
